# Trends Checker & Macro Wave Skill

## 1. Wave Classification
- **Permanent Shift (Build Here):** Continuous growth over 24+ months (e.g. AI infrastructure, self-hosted developer tools, privacy-first analytics).
- **Temporary Fad (Avoid):** Sudden spike followed by 80% collapse in search volume within 6 months.

## 2. GitHub Trending Saturation Test
- Search GitHub repositories for similar open-source projects.
- Check star velocity and open issues: If existing repos have 100+ open feature requests that the maintainers are ignoring, that indicates an unmet commercial market need!
