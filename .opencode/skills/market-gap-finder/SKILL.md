# Market Gap Finder Skill

When invoked, execute the following systematic process:

## 1. Friction Phrase Mining
Search Reddit, forums, and Twitter for the target domain using these exact friction triggers:
- `"I hate [tool/process]"`
- `"This sucks because..."`
- `"Can't find a good tool for..."`
- `"Why is there no simple alternative to..."`
- `"Struggling to automate..."`
- `"Too expensive for small teams"`
- `"Nightmare setup / breaking constantly"`

## 2. Workaround Discovery
Look for posts where users describe:
- Cobbling together 3 different tools with Zapier or manual Python scripts.
- Maintaining messy Excel/Google Sheets to manage operational data.
- Asking for open-source self-hosted replacements to expensive enterprise SaaS.

## 3. Unbundling Analysis
Evaluate if large incumbents (e.g., Salesforce, Jira, Datadog, Stripe) have bloated features that can be extracted and delivered as a standalone 10x simpler tool.

## 4. Synthesize Opportunity
Format results into a structured opportunity dossier with real quotes, links, competitor flaws, and a 2-3 week MVP spec.
