# Startup Validator Skill (Brutal Honesty Framework)

Use this skill to evaluate any synthesized startup concept against hard economic and founder reality.

## The 8 Validation Filters:
1. **Hair-on-Fire Problem Test:** Is this an acute, painful workflow blocker that people are actively searching to solve today, or a "nice-to-have" vitamin?
2. **Willingness to Pay (B2B vs B2C):** Do target users have corporate budgets ($49-$299/mo), or are they price-sensitive hobbyists?
3. **Build Feasibility (2-3 Week Rule):** Can a solo founder build a functional v1 in 2-3 weeks using Next.js + Supabase + APIs?
4. **Saturation & Incumbent Moat:** Run `idea-reality-mcp` or GitHub search. Are there 50 identical open-source repos or well-funded venture clones?
5. **Distribution & Acquisition Channel:** Where are the first 100 users? (e.g., specific subreddits, cold email via tech stack datasets, LinkedIn).
6. **Regulatory / Compliance Burden:** Does this require SOC2, HIPAA, banking charters, or complex enterprise procurement? (If yes, KILL immediately).
7. **Churn Risk:** Is this a tool used once and discarded, or an embedded recurring daily/weekly workflow?
8. **Fake Door Test Readiness:** Can we build a 1-page Framer/Vercel landing page + 3-question Tally quiz to test demand before writing code?
